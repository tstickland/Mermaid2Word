Mermaid Diagrams for Word

Write Mermaid code in Word and insert crisp, editable diagrams. Install it once using the steps for your version of Word. After that, updates arrive automatically.

Word on Windows

Open PowerShell (Start menu → type "PowerShell") and paste:

irm __ADDIN_BASE_URL__install/install-windows.ps1 | iex

Close all Word windows and reopen Word. Then go to Home → Add-ins and choose Mermaid Diagrams (under Developer Add-ins). After that first time, it also has its own button at Insert → Mermaid Diagram.

This installs for your Windows account only and doesn't need admin rights. You can read the script first.

Word on Mac

Open Terminal and paste:

curl -fsSL __ADDIN_BASE_URL__install/install-mac.sh | bash

Quit Word completely (Word → Quit Word) and reopen it. Then open the add-in from the Add-ins button (on the Home or Insert tab, depending on your Word version) and choose Mermaid Diagrams. After that first time, look for Insert → Mermaid Diagram.

Read the script.

Word on the web

  1. Download the manifest
  2. In Word on the web, open a document and go to Home → Add-ins → More Add-ins.
  3. Choose Upload My Add-in (under My Add-ins) and select the downloaded file.

Using it

  • Pick a Template or write Mermaid code, check the preview, then click Insert.
  • To edit a diagram, click it in the document, click Load selected, change the code, then click Update selected.
  • Type a code block in your document (```mermaid, the code, then ```, each on its own line) and click Convert code blocks to turn it into a diagram.

Uninstall

Windows (PowerShell):

irm __ADDIN_BASE_URL__install/uninstall-windows.ps1 | iex

Mac (Terminal):

curl -fsSL __ADDIN_BASE_URL__install/uninstall-mac.sh | bash

Word on the web: Add-ins → My Add-ins, open the add-in's … menu and choose Remove.
